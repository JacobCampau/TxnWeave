# TxnWeave
## What is TxnWeave?
A graphing web application meant to assist retail security agents in identifying suspicious activity and visually understanding long term fraud cases. Developed with gift card fraud in mind, this web application allows users to fill out information from their stores and then see this information graphed to better find patterns and suspicious behavior in their stores.
